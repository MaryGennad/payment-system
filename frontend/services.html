Описание услуг

Что вы оплачиваете:

  • Привязка карты (1 ₽) — одноразовая услуга по безопасному сохранению платежных данных для будущих транзакций.
  • Пакет автоплатежей (5 ₽) — пакет из 5 рекуррентных списаний по 1 ₽ для тестирования или оплаты регулярных сервисов без подтверждения.
  • Консультация (10 ₽) — разовая услуга по оказанию технической поддержки.

Процесс оплаты:

  1. Выберите услугу и нажмите «Выбрать».
  2. Укажите email для получения электронного чека (54-ФЗ).
  3. Перейдите на защищенную страницу ЮKassa для ввода данных карты.
  4. После успешной оплаты услуга активируется автоматически.
